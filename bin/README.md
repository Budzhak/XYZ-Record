# XYZ Запись

Программа для быстрой записи экрана со звуком с микрофона — «прибор» в стиле плагина XYZ. Записывает весь рабочий стол в MP4 (H.264 + AAC), умеет ставить запись на паузу и улучшать голос после записи.

Установка не нужна: программа запускается прямо из папки.

## Как запустить

1. Скопируйте (или синхронизируйте через Яндекс.Диск) папку **«XYZ Запись»** целиком — вместе с подпапкой `ffmpeg`.
2. Запустите **`XYZ Запись.exe`**.
3. При первом запуске Windows может показать синее окно SmartScreen «Система Windows защитила ваш компьютер» — нажмите **«Подробнее» → «Выполнить в любом случае»**. Программа не подписана цифровой подписью, поэтому так бывает при первом запуске на новом компьютере.

Если удобно — создайте ярлык на рабочем столе: правой кнопкой по `XYZ Запись.exe` → «Отправить» → «Рабочий стол (создать ярлык)».

## Управление

| Что | Как |
|---|---|
| Начать / остановить запись | красный пэд «Запись» / «Стоп» на приборе или клавиша **F9** (работает из любого окна) |
| Пауза | янтарный пэд «Пауза» |
| Тумблер **«Питание»** | выключить прибор — он прячется в трей (значок у часов), вернуть — щелчок по значку |
| Тумблер **«Облик»** | вверх — «Корпус», вниз — «Рамка» (корпус исчезает, остаётся светящийся контур) |
| Перетаскивание | за корпус (в облике «Рамка» — за контур и элементы) |
| Меню | **правая кнопка мыши** по прибору: начать запись (F9), микрофон / «Без звука», **«Улучшить голос»**, «Папка для записей…», «Открыть папку», «Поверх всех окон», «Показывать прибор в записи», «Сворачивать в плашку при записи», облик, щелчок тумблера, выключить в трей, выход |

Во время записи сам прибор и его меню в видео не попадают.

## «Улучшить голос»

Пункт меню правой кнопки. После остановки записи программа делает второй проход: убирает гул и шум, выравнивает громкость, смягчает шипящие. Видео при этом не перекодируется. Оригинальная запись без обработки сохраняется в подпапку `_raw` рядом с итоговым файлом.

## Куда сохраняются записи

По умолчанию — на **Рабочий стол**, файлы вида `zamechaniya_2026-11-02_1030.mp4`. Другую папку можно выбрать в меню: «Папка для записей…»; «Открыть папку» — открывает её в Проводнике.

Настройки (папка, микрофон, облик и т. п.) хранятся в `%APPDATA%\XYZ\recorder.ini` — на каждом компьютере свои.

## Микрофон

Если в записи нет звука или прибор пишет «Звук не запишется»:

- **Параметры Windows → Конфиденциальность и защита → Микрофон** — включите «Доступ к микрофону» и «Разрешить классическим приложениям доступ к микрофону».
- Выберите нужный микрофон в меню правой кнопки (пункт «Обновить список», если подключили его после запуска).

## ffmpeg

Запись выполняет ffmpeg — он лежит в подпапке `ffmpeg\` (ffmpeg.exe и библиотеки DLL, ~88 МБ). Программа ищет ffmpeg в таком порядке:

1. `ffmpeg.exe` рядом с `XYZ Запись.exe`;
2. `ffmpeg\ffmpeg.exe` рядом с программой;
3. `C:\Program Files\Shotcut\ffmpeg.exe` (если установлен Shotcut);
4. переменная PATH.

Если ничего не найдено, на экране прибора будет надпись «Не найден ffmpeg — положите ffmpeg.exe рядом с программой». Взять ffmpeg можно из установленного [Shotcut](https://shotcut.org) (папка программы — ffmpeg.exe и все DLL рядом) или с [ffmpeg.org](https://ffmpeg.org/download.html) (подойдёт любая сборка для Windows с libx264).

## Системные требования

- Windows 10 или 11, 64-разрядная;
- .NET Framework 4.x — уже встроен в Windows 10/11, ставить ничего не нужно;
- микрофон (для записи со звуком).

## Исходники и сборка

Исходник — `src/RecorderDevice.cs` (C#, WinForms, один файл), графика — `src/res/*.png`. Сборка встроенным компилятором .NET Framework — `src/build.cmd` (Visual Studio не нужна). Готовая портабельная папка — `bin/`.
